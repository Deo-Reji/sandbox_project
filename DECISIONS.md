# DECISIONS.md

Decisions not covered by the brief, with the reason. Newest at the bottom.

1. **Pyodide 0.28.3 pinned** (`https://cdn.jsdelivr.net/pyodide/v0.28.3/full/`). Ships pandas 2.3.1 / numpy 2.2.5. The only CDN dependency; everything else is vendored.
2. **No Faker.** `data/generate.py` uses only the standard library with a fixed seed, so anyone can regenerate the data with a bare Python install.
3. **Expected outputs are generated by `data/build_expected.py`** using CPython's `sqlite3` (same SQLite dialect as sql.js) and local pandas. The Playwright harness then re‑runs every solution through the real browser engines and asserts PASS, so Python‑side and browser‑side results must agree. Excel expected values come from a pandas "oracle" expression per problem, so the HyperFormula formula is cross‑checked against an independent computation.
4. **ER diagrams are a tiny home‑grown SVG renderer** (`js/ui/erd.js`) driven by PRAGMA output, used both for the dataset schema drawer and for the "what you built" view on the Database Design tab. Mermaid would add ~2 MB of vendored JS for a single diagram.
5. **HyperFormula function policy**: only functions present in `HyperFormula.getRegisteredFunctionNames()` for 3.5.0 are taught or tested. Notable absences that shaped the Excel problems: no `CONCAT` (use `CONCATENATE` or `&`), no `AVERAGEIFS` (use `SUMIFS/COUNTIFS`), no `LET`, no `RANK`. `XLOOKUP`, `FILTER`, `UNIQUE`, `SORT` exist but are left out of v1 as the brief asked.
6. **Pandas I/O blocking is best‑effort**: in the worker, `open` is replaced, and `socket`, `urllib`, `http`, `requests`, `pyodide.http`, `js`, `subprocess`, `pathlib` file ops are poisoned via `sys.modules`. It is a browser sandbox on the user's own machine, so this exists to keep problems honest, not as a security boundary.
7. **DB Design grading DSL**: hidden checks are JSON steps (`sql_ok`, `sql_fail`, `query_equals`, `fk_exists`, `columns_not_together`, `column_in_pk`, `unique_on`, …) evaluated against PRAGMA tables. Prompts name tables/columns only where the behavioural inserts need them.
8. **Hash routes**: `#<track>/<item>` where item is `tutorial`, `sandbox`, `easy-1 … hard-5`, or `challenge-N` for Exploration.
